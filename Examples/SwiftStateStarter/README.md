# SwiftState Starter

This folder contains a single-file SwiftUI starter you can paste into a new Xcode SwiftUI app after adding SwiftState with Swift Package Manager.

## Try It In Xcode

1. Create a new SwiftUI app in Xcode.
2. Add SwiftState with `File > Add Package Dependencies...`.
3. Use this package URL:

```text
https://github.com/ChiefVenzox/SwiftState.git
```

4. Replace the generated app file with `SwiftStateStarter.swift`.
5. Run the app.

The starter demonstrates:

- Store setup in `@main`
- State and action definitions
- Synchronous reducer updates
- Async effects
- SwiftUI binding helper
- Time travel debugger overlay in debug builds
